# Upstox Trade Markers

A small React + Express application for visualizing trade markers on a chart.

## Structure

- `frontend/` — React frontend
- `backend/` — Express backend
  - `routes/` — API routes
  - `services/` — backend/business logic

## Setup

### Frontend

```bash
cd frontend
npm install
npm install lightweight-charts
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```
